# 规划路线图

## 总体目标

建立一个可审计、可测试的免费听任务实验项目：离线域完整演示任务流程，真实账号域只做权益查询和经过门禁的播放验证。

## 阶段路线

| 阶段 | 目标 | 状态 | 验证门槛 |
| --- | --- | --- | --- |
| P0 | 离线任务、点击、停留、领取回执与幂等模型 | 已完成 | 离线测试通过 |
| P1 | CLI 全自动执行器与结构化审计轨迹 | 已完成 | 四场景自动运行；网络请求恒为 0；失败场景余额不增加 |
| P2 | 真实账号登录和免费听权益只读门禁 | 已完成 | 门禁测试通过；零余额阻止播放探针 |
| P3 | 自动筛选 VIP 候选并执行有界播放验证 | 已完成实现 | 仅在权益大于 0 时运行；候选、请求次数和读取字节数有上限 |
| P4 | 显式桌面启动器包装 | 已完成实现 | 用户主动运行启动器；客户端启动失败或门禁失败时立即暴露错误 |
| P5 | 发布与回归 | 进行中 | 文档、测试、演示输出和公开分支一致 |

## 阶段依赖

```text
P0 → P1
P2 → P3 → P4 → P5
P1 ────────────┘
```

P1 与真实账号链路隔离，可以独立交付。P3 依赖通过官方手机端任务取得真实权益；P4 依赖 P3 的接口和退出码稳定。

## 固定边界

- 离线执行器只操作本地内存对象，不访问网易云或任何广告服务。
- 真实账号自动提交广告完成、点击、停留和领奖请求不进入路线图。
- 桌面集成采用显式启动器，不注入网易云进程，不安装隐藏常驻组件。
