# 项目文档索引

## 项目定位

本项目用于验证“免费听广告任务”的状态机、失败分支和回执幂等性，并提供真实账号权益的只读到账门禁。

项目包含两个严格隔离的运行域：

1. 离线演示域：使用虚拟时间、演示任务和演示回执，网络请求数恒为 0。
2. 真实账号只读域：读取当前 Windows 用户的网易云桌面会话，仅查询登录状态和免费听剩余时长。

## 全局边界

- “模拟点击、模拟停留、自动领取”只作用于本地 `DemoServer`，所有回执均标记为演示数据。
- 真实账号链路只读，不提交广告监控、观看完成、点击、停留或权益领取请求。
- Cookie 仅在进程内存中使用，日志和输出不得包含账号原值、Cookie、Token 或设备标识。
- 任何真实播放探针都必须经过 `rightsRemainingTime > 0` 门禁，且设置超时、响应大小和请求次数上限。
- 桌面启动器只能由用户显式执行，不注册自启、计划任务或常驻服务。
