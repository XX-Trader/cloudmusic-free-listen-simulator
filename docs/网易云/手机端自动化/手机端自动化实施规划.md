# 手机端自动化实施规划

## 1. 当前阶段

P5：实现手机端自动化模块 `device_automation.py`，把官方任务流程、到账轮询与播放验证串成一条命令。

## 2. 变更影响分析

### 新增文件

- `device_automation.py`
- `tests/test_device_automation.py`
- `docs/网易云/手机端自动化/` 三件套

### 修改文件

- `README.md`、`docs/INDEX.md`、`docs/规划路线图.md`、`todo.md`、`done.md`

### 直接影响

- 仓库多一个依赖 ADB 的入口；离线模拟与只读脚本不受影响。

### 配置与兼容性

- 新增参数：`--serial`、`--adb`、`--wait-seconds`、`--stay-seconds`。
- 不新增第三方依赖，只用标准库 `subprocess` 与 `xml.etree`。

## 3. 分步实施

### 步骤 1：ADB 封装

1. 解析 `adb devices -l` 选出 `device` 状态设备。
2. 封装 shell、`exec-out`、点击、按键、前台 Activity 读取。
3. 界面 dump 采用 `/sdcard` 落地后 `exec-out cat` 读回，避免依赖 pull 路径转换。

验证点：假设备可注入，命令调用序列可断言。

### 步骤 2：界面定位

1. 解析 `uiautomator` XML 为节点树。
2. 实现文案、描述、resource-id 三级匹配与中心点计算。
3. dump 失败重试，仍失败抛错。

验证点：命中结果与坐标计算有单测覆盖。

### 步骤 3：流程编排

1. 启动应用并等待前台。
2. 依次定位并点击：免费听标签 → 领 30 分钟 / 看广告免费听 → 进入落地页查看详情。
3. 处理系统“是否允许打开应用”弹窗。
4. 停留满 8 秒后有界返回网易云。

验证点：假设备上断言点击顺序与停留时长。

### 步骤 4：到账与验证

1. 复用 `account_gate.wait_for_rights` 轮询。
2. 复用 `vip_probe.run_probe` 验证播放。
3. 汇总步骤轨迹与结论。

验证点：未到账返回退出码 2；到账且放行返回 0。

### 步骤 5：回归与实机

1. 全量单元测试。
2. 真机跑一次完整流程，核对到账与播放结论。

## 4. 防重构破坏策略

- 只读脚本 `account_gate.py`、`vip_probe.py` 的公开接口不变。
- 离线模拟器不依赖 ADB，测试环境无设备也能全绿。
- 文案常量集中在模块顶部，便于改版后同步。

## 5. 完成定义

- 单元测试通过且不依赖真机。
- 真机跑通一次，输出 `entitlement_detected` 与 `vip_playback_verified`。
- 审计输出不含凭证与设备标识。
