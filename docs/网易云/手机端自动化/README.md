# 手机端自动化

## 1. 目标

在用户自己的手机上，通过 ADB 驱动网易云官方客户端走完免费听任务，并把整条链路串成一条可重复执行、可审计的命令：

```text
连接设备 → 启动网易云 → 进入免费听 → 打开广告任务 → 点击落地页并停留 8 秒
→ 返回客户端 → 轮询权益到账 → 验证 VIP 播放
```

自动化只操作官方客户端的可见界面，不构造、不重放任何接口请求，不提取账号凭证。

## 3. 范围边界

### 范围内

- 通过 ADB 操作官方客户端界面元素。
- 系统弹窗的“允许打开某应用”确认。
- 到账轮询与只读播放验证。

### 范围外

- 直接调用网易云广告、监控或领奖接口。
- 提取、导出或持久化 Cookie、Token、OAID 等设备与账号标识。
- 伪造设备指纹、绕过 `/eapi/ad/sniffing` 的反自动化检测。
- 批量、循环或多账号执行广告任务。
- 修改客户端文件、注入进程。

## 4. 业务规则

1. 只在 `device` 状态的设备上操作；未连接直接报错。
2. 元素定位优先用文案，其次用 resource-id，最后才用固定坐标。
3. 每次点击前重新读取界面结构，避免坐标漂移。
4. 广告选择页下滑一屏后，取最下方的“看广告 免费听”按钮。
5. 同名文案同时出现在标题与按钮时，按宽度过滤掉标题节点。
6. 落地页停留时间不少于任务要求的 8 秒。
7. 返回客户端最多尝试 5 次 BACK；前台不变即停止并如实报告。
8. 权益轮询窗口有界，默认 90 秒；网络抖动自动重试。
9. 任一步失败都保留原始错误与已完成的步骤记录，不静默跳过。
10. 单次运行只完成一个广告任务，不做循环。
11. 结论以服务端权益为准：手机端没走通但权益已到账时，仍以权益与播放验证判定。

## 5. 验收标准

- 无设备时退出码 5，且不产生任何点击。
- 全流程成功时退出码 0，输出含 `entitlement_detected: true` 与 `vip_playback_verified: true`。
- 权益未到账时退出码 2，并给出 `gate_closed` 结论。
- 步骤轨迹 `steps` 按顺序记录每一步的名称与结果。
- 输出含 `baseline_rights` 与 `rights_delta`，可看出权益变化。
- 单元测试断言点击顺序基于文案而非坐标。

## 6. 风险与限制

- 客户端改版会改变文案与控件，定位失败时需同步更新文案常量。
- 界面动画或视频广告期间 `uiautomator` 拿不到空闲态；实现会重试并改用登记的坐标兜底点。
- 平台存在广告自动化嗅探，账号存在被风控的可能；本工具面向个人单次使用。
- 落地页跳转可能被系统应用锁拦截，这类验证必须由用户本人完成。
- 每日任务次数受平台限制，重复运行会因已达上限而无法到账。

## 7. 工具与运行

- ADB：`C:\Users\ma\AppData\Local\Android\platform-tools\adb.exe`
- Python 3.10+，`cryptography`（读取桌面会话）

```pwsh
pwsh -NoProfile -Command "python -B ./device_automation.py"
pwsh -NoProfile -Command "python -B ./device_automation.py --serial <设备序列号> --wait-seconds 120"
```

退出码：`0` 全部通过、`2` 权益未到账、`3` 播放验证未放行、`5` 无设备、`6` 手机端流程失败。

## 8. 后续方向

可把启动器 `start_desktop.ps1` 与本模块串成一条命令：先在手机上完成任务，再在电脑上验证权益与播放。
