# 免费听离线模拟

## 1. 目标

在完全离线的演示环境中，自动执行以下流程：

1. 本地演示服务签发广告任务。
2. 自动记录“开始广告”和“点击广告”模拟事件。
3. 使用虚拟时间满足或故意违反停留门槛。
4. 自动向本地演示服务领取奖励。
5. 输出可审计的事件轨迹、演示回执和演示余额。

该功能用于验证客户端状态机和回执处理，不代表真实广告观看，也不产生真实免费听权益。

## 2. 子功能与状态

| 子功能 | 状态 | 验收依据 |
| --- | --- | --- |
| 演示任务签发 | 已完成 | 任务包含方法、停留门槛、奖励和过期时间 |
| 模拟点击 | 已完成基础版 | 原始点击时间不可被重复点击覆盖 |
| 自动停留与领取 | 进行中 | CLI 自动执行，输出结构化虚拟时间轨迹 |
| 失败分支 | 已完成基础版 | 停留不足、过期、未知任务、时间倒退、服务拒绝均不增加余额 |
| 重复领取幂等 | 已完成基础版 | 同一任务返回同一回执且只增加一次余额 |
| 自动化测试 | 进行中 | 四个 CLI 场景和底层边界测试全部通过 |

## 3. 范围边界

### 范围内

- 本地内存中的演示任务、演示点击、虚拟停留和演示领奖。
- 结构化审计事件与明确的 `offline_demo` 标记。
- 成功、停留不足、服务拒绝和重复领取场景。
- Python CLI 和 PowerShell 启动入口。

### 范围外

- 调用网易云或广告平台的任务、监控、点击、观看完成和领奖接口。
- 模拟设备身份、伪造广告证明、修改客户端或注入进程。
- 保存或输出真实账号 Cookie、Token、设备标识和广告标识。
- 将演示余额解释为真实权益。

真实权益由用户在官方手机端完成任务后取得；本仓库的 `account_gate.py` 只读检测到账状态。

## 4. 业务规则

1. 演示任务必须存在且处于有效期内。
2. 点击时间只记录第一次成功点击。
3. `click_stay` 任务必须满足 `领取时间 - 点击时间 >= 停留秒数`。
4. 时间倒退立即拒绝领取。
5. 演示服务拒绝时，客户端状态必须进入 `rejected`。
6. 同一任务成功领取后再次领取，返回原回执且余额不重复增加。
7. 任意 CLI 场景必须输出：
   - `mode = offline_demo`
   - `network_requests = 0`
   - `real_entitlement_granted = false`
   - `receipt.demo = true`

## 5. 验收标准

- `success`：自动开始、点击、停留和领取；演示余额为 30 分钟。
- `short-stay`：自动点击但停留不足；演示余额为 0。
- `server-rejected`：停留满足但演示服务拒绝；演示余额为 0。
- `duplicate`：自动领取后再领取一次；两次回执一致，演示余额仍为 30。
- 每个场景输出按顺序排列的审计事件，事件包含虚拟时间、动作和结果。
- 单元测试不得访问网络或读取真实桌面会话。

## 6. 风险与限制

- 固定的停留秒数和奖励分钟数仅为测试参数，不表示平台当前规则。
- UUID 使任务和回执标识每次不同，测试只断言格式和关联关系，不依赖固定值。
- 虚拟时间只验证状态转换，不证明现实中发生过广告观看。

## 7. 工具与运行

- Python 3.10+
- PowerShell 7
- Python 标准库 `unittest`

不为离线执行器新增第三方依赖。
