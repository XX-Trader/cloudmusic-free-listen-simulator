# 桌面启动器

## 1. 目标

提供一个用户显式运行的桌面入口，把“启动网易云客户端 → 等待会话就绪 → 只读权益门禁 → 可选播放验证”串成一条可观察的流程。

启动器不常驻、不自启、不注入客户端，只在被用户主动执行时运行一次并输出结论。

## 2. 子功能与状态

| 子功能 | 状态 | 验收依据 |
| --- | --- | --- |
| 客户端路径解析 | 已完成 | 参数优先，其次按候选列表与运行进程解析 |
| 按需启动客户端 | 已完成 | `-StartClient` 显式开启，默认不启动 |
| 会话就绪等待 | 已完成 | 有界等待，超时如实报错 |
| 权益门禁联动 | 已完成 | 调用 `account_gate.py` 并解析 JSON |
| 播放验证联动 | 已完成 | `-Probe` 开关控制，默认不执行 |
| 结论汇总 | 已完成 | 输出一份 JSON 摘要与退出码 |
| 脚本级测试 | 已完成 | 用桩解释器验证汇总结构 |

## 3. 范围边界

### 范围内

- 启动本机已安装的网易云桌面客户端。
- 调用只读门禁与只读播放探针。
- 输出一份 JSON 摘要和退出码。

### 范围外

- 注册开机自启、计划任务或系统服务。
- 注入客户端进程、修改客户端文件或读写客户端私有数据。
- 自动点击广告、自动停留、自动领取权益。
- 在后台常驻或隐藏运行。

## 4. 业务规则

1. 启动器只能由用户显式执行，默认不启动客户端。
2. 客户端路径解析顺序：显式参数 → 运行中进程 → 候选安装路径。
3. 找不到可执行文件时如实报错，不猜测路径。
4. 等待超时按等待秒数上限收敛，超时后仍继续执行门禁并如实报告状态。
5. 门禁脚本失败时保留其原始退出码与输出，不吞异常。
6. 探针仅在 `-Probe` 开启时执行。
7. 摘要不包含 Cookie、Token 与账号原值。

## 5. 验收标准

```pwsh
pwsh -NoProfile -File ./start_desktop.ps1
pwsh -NoProfile -File ./start_desktop.ps1 -StartClient
pwsh -NoProfile -File ./start_desktop.ps1 -StartClient -Probe
```

- 默认执行：只跑门禁，客户端是否启动由 `-StartClient` 决定。
- 输出 JSON 含 `client`、`gate`、`probe`、`exit_code`。
- 权益为 0 时 `gate.ready_for_vip_probe` 为假，退出码 2。
- 权益有效且探针放行时退出码 0。

## 6. 风险与限制

- 客户端版本变化可能改变可执行文件名，路径解析失败时需用 `-ClientPath` 指定。
- 门禁需要 `cryptography` 依赖；缺少时脚本会报出原始错误，提示先建虚拟环境。
- 客户端刚启动时 Cookie 库可能尚未写盘，门禁可能读不到会话；可重跑一次。

## 7. 工具与运行

- PowerShell 7
- Python 3.10+（读取会话需要 `cryptography`）

## 8. 后续方向

若需要“客户端起来后自动跑一次”，可由用户手动把本脚本挂到任务计划，仍保持显式可关闭，不引入隐藏常驻。
