## 3. 分步实施

### 步骤 1：定位客户端

1. 查询运行中的网易云进程路径。
2. 校验候选安装路径。
3. 确认实际路径为 `D:\Programs\CloudMusic\cloudmusic.exe`。

验证点：路径解析在无进程时仍能从候选列表命中。

### 步骤 2：实现启动器

1. 解析路径与运行状态。
2. 按 `-StartClient` 决定是否启动。
3. 有界等待进程就绪。
4. 调用只读门禁，解析 JSON。
5. 按 `-Probe` 调用播放探针。
6. 输出摘要 JSON 与退出码。

验证点：任何一步失败都保留原始错误与退出码。

### 步骤 3：脚本级测试

1. 用桩解释器返回固定门禁 JSON，校验摘要结构。
2. 静态检查脚本不含注册表、计划任务与服务相关操作。

验证点：测试不启动真实客户端，不触网。

### 步骤 4：实机运行

1. 不带 `-StartClient` 执行，验证门禁结论与退出码。
2. 带 `-StartClient` 执行，验证客户端启动与等待逻辑。

## 4. 防重构破坏策略

- 启动器与 Python 模块通过进程与 JSON 解耦，互不 import。
- 退出码语义在架构文档中固定，测试锁定。
- 默认不启动客户端，避免测试环境产生副作用。

## 5. 完成定义

- 脚本级测试通过。
- 实机两种模式均输出合法 JSON 摘要。
- 摘要不含凭证。
